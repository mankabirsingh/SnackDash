# SnackDash 🍕📱

SnackDash is a food delivery Android application built using Kotlin, ViewBinding, and Material Design 3. It features:

- Modern splash screen (Android 12+)
- OTP login flow
- Location handling
- Reorder past items (RecyclerView)
- Beautiful UI with custom fonts and image slideshow

## Tech Stack

- Kotlin
- Android ViewBinding
- Material3 (M3)
- Core SplashScreen API
- ConstraintLayout, CardView, RecyclerView
- GitHub-hosted
